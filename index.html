🛡️ Security & Privacy Architecture

🔑
No Hardcoded Secret Keys (CWE-798)
Powered by default by Open-Meteo's open API. Eliminates credential leakage, theft, and unauthorized billing risks.
🛡️
Strict Content Security Policy (CSP)
Restricts script execution to 'self' and locks external connections exclusively to legitimate weather APIs.
🚫
Cross-Site Scripting (XSS) Immunity (CWE-79)
All user queries and dynamic API responses are sanitized and inserted using native DOM textContent sinks.
⏱️
DoS & Timeout Safeguards (CWE-400)
Equipped with 8-second AbortController timeouts, request throttling, and input length capping.
📍
Privacy-Friendly Geolocation
GPS coordinates are strictly requested on-demand with explicit consent and never tracked or persisted remotely.
